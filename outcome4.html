The acronym of "ML" in the field of AI&ML stands for Machine Learning and it's basically where we train the AI models using statistical algorithm to find pattern in data, make predictions, decision, or content without following rigid rules written by a programmer. The model would learns from these training data to apply them onto new data. There are three main type of Machine Learning, Supervised Learning, Unsupervised Learning, and Reinforment Learning

Supervised Learning

Supervised Learning is basically is when the training data includes both the input and the correct answer so in the future they can predict the outcomes of one situation. Think of spam email, programmer will give the model multiple of past spam email and train it to detect whether the incoming mail is spam or not. For example, if the training email contain a lot of mails about subscription to some site, and the new inbox come with content about subscription, the model will put it into the spam list. Supervised Learning often have two main algorithm to help the model predict the outcome which are Linear Regression and Decision Tree

Reinforment Learning

Reinforment Learning is when we train a model through trial and error using rewards or penalties based on its action. The goal when applying this type of training onto the model is because we want it to learn what is the best sequence of actions. Often, the algorithm that Reinforment Learnign associate with is Q-Learning
